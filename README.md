# Social-Dashboard
A Power BI dashboard designed to provide real-time insights from social media platforms such as Twitter and Reddit. This project focuses on analyzing public sentiment, tracking keyword trends, and visualizing social media engagement to support brand monitoring and marketing strategies.

## 🧠 Overview

This dashboard enables users to:

- Monitor social media activity around specific topics, keywords, or hashtags
- Analyze sentiment (positive, negative, neutral)
- Identify top-performing posts or users
- Visualize mentions over time and by geography
- Discover trending terms and topics
